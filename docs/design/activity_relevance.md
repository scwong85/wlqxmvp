# Activity relevance audit (M6-16)

Rule: no decorative activity. Each one must feed a system that matters for the 7-day run.
"Live now" means the effect is already usable; "Planned" names the milestone that consumes it.

| Activity | Approaches | Produces | Used by | Status |
|---|---|---|---|---|
| Training 练功 | power focus / body focus | Power, Body | Combat stats (M9), health and stamina caps | Body live now (caps); combat M9 |
| Technique practice 练招 | safe / balanced / risky | Path progress, Agility | Technique unlocks (live), combat techniques (M9) | Live now |
| Meditation 打坐 | none | Insight, stamina | Stamina economy, Insight checks | Live now |
| Fishing 钓鱼 | still water / rapids | Food, coins | Cooking, economy | Live now |
| Herb gathering 采药 | valley / cliff | Herbs, Insight | Medicine for recovery in combat (M9) | Planned M9 |
| Mining 挖矿 | shallow / deep | Ore, coins | Equipment and shop (M12) | Planned M12 |
| Hunting 打猎 | hare / boar | Food, coins | Cooking, economy | Live now |
| Cooking 烹饪 | porridge / feast | Stamina, timed buff | Buffs feed skill checks now; combat buffs M9 | Live now |
| Music 音律 | for Shen / for Lu / solo | Spirit, affinity | Recruitment and dialogue (M7, M12) | Affinity stored; used M7 |
| Chess 棋局 | casual / master | Insight, strategy token | Tokens spent in combat (M9) | Planned M9 |
| Social visit 访友 | Bai / gift Bai / Shen / Lu | Affinity | Recruitment, dialogue, endings (M7, M12, M13) | Affinity stored; used M7 |
| Rest 休息 | none | Stamina | Pacing the 14 slots | Live now |

Zero decorative activities. Items that are only stored until a later milestone: herbs/medicine (M9), ore (M12),
strategy tokens (M9), affinity (M7). If one of those milestones drops its consumer, that activity must be cut or reworked.
