# Story bible (M15)

The single source of truth for the campaign. Draft status: proposed by Claude, approved in outline by the project owner (world, companions, endings). Anything marked *open* is still to be decided.

| File | Contents |
|---|---|
| `WORLD.md` | Setting, history, regions, areas, factions, martial-arts system, rules of the world |
| `CHARACTERS.md` | The hero, 8 companions, antagonists, recurring NPCs |
| `ARCS_AND_ENDINGS.md` | Companion arcs (stages, relationship branches, outcome tags) and the 5 big endings with epilogue tags |
| `TIMELINE.md` | The 3-year calendar, seasons, festivals, the quarter-by-quarter main plot, the opening month schedule |
| `STYLE_GUIDE.md` | Voice per character, vocabulary, name glossary (Chinese / pinyin / English), writing rules, content limits |

Rules for writers (and for me): names come from the glossary; a fact stated here wins over any scene; new facts are added here first; every scene lists which flags it reads and sets (`flags.md` is produced in M16 by the event tooling).
